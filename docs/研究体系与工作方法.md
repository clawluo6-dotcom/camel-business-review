## 四、工作方法与协作规范

### 4.1 研究协作流程

```
提出课题 → 文献回顾 → 建立框架 → 深入分析 → 形成文章 → 审校发布
    ↑                                                    │
    └────────────── 反馈迭代 ←────────────────────────────┘
```

1. **提出课题**：你提出研究方向或具体问题
2. **文献回顾**：我检索 Obsidian 知识库现有内容 + 网络最新资料
3. **建立框架**：我搭文章结构，你确认方向
4. **深入分析**：我撰写初稿，你补充实务见解
5. **形成文章**：定稿为 Markdown，存入 Obsidian
6. **审校发布**：验证语法 → 推送 GitHub → 跨平台分发

### 4.2 写作规范

- **署名格式**：作者：骆新中-骆驼商业本质 | 日期
- **文章末尾**：文末回流脚注，引回原站
- **引号规则**：正文使用中文引号「」或 Unicode 智能引号，严禁 ASCII 直引号
- **标题编号**：用中文序号（一、二、三、）或阿拉伯数字，保持系列一致性
- **子分类名**：禁止 ASCII 双引号，用「」代替

### 4.3 技术铁律

#### 铁律一：JS 语法验证（每次必做）

修改 site-data.js 或 article-content.js 后，必须执行：

```bash
node -e "const fs=require('fs');const vm=require('vm');
try{vm.runInNewContext(fs.readFileSync('site-data.js','utf-8'),{window:{}});console.log('OK')}catch(e){console.error(e.message)}"
```

检查项：
- [ ] 无双逗号
- [ ] summary 字段无 ASCII 直引号
- [ ] 语法验证通过

#### 铁律二：推送用 gh api（非 git push）

沙箱拦截 git push/SSH，一律用 GitHub Git Data API：

```
GET ref → POST blobs → POST trees(base_tree=HEAD) → POST commits → PATCH ref
```

本地代理 7890 未运行时：env -u HTTP_PROXY -u HTTPS_PROXY gh api ...

#### 铁律三：EPERM 绕过

macOS 14+ 的 com.apple.provenance 属性导致写入失败时：

```bash
# 可行方案
rm -f target.js && cp /tmp/new_version.js target.js
# 不可行：xattr -c / mv / Python os.replace()
```

#### 铁律四：安全红线

- 绝不把 Token / 密码 / API Key 贴进对话
- GitHub 登录：在 Mac 终端跑 gh auth login
- 误贴 token：不回显、不存盘，立即提醒 Revoke

#### 铁律五：完整发布流程（6步）

| 步骤 | 操作 | 检查点 |
|------|------|--------|
| 1. 备份 | cp 备份 JS 文件 | 备份存在 |
| 2. 修改 | 更新 site-data.js + article-content.js | 引号规则合规 |
| 3. 验证 | node --check 验证语法 | 两个文件都 OK |
| 4. 预览 | 浏览器打开 social.html → Cmd+Shift+R | 文章列表正确 |
| 5. 推送 | gh api Git Data API 推送 | GitHub 返回 200 |
| 6. 确认 | 打开线上链接确认 | 新文章可见 |

#### 铁律六：Obsidian 目录名

Obsidian 真实目录名使用中文智能引号（U+201C/U+201D），不是 ASCII。填 DIRECTORY_MAP 或脚本路径时必须用 Unicode。

### 4.4 文件同步拓扑

| 位置 | 用途 | 规则 |
|------|------|------|
| GitHub 仓库 | 网站唯一真身 | 每台电脑只留 1 个本地 git 仓库 |
| iCloud (Obsidian) | 知识库同步 | 知识输入源，只读参考 |
| iCloud/WorkBuddy-sync | 非git文件同步 | MEMORY.md / skills / 记忆 |
| 网站 git 仓库 | 绝不放进 iCloud | 避免 git + iCloud 双引擎冲突 |
